# Akash S Kumar — Portfolio

Personal portfolio of Akash S Kumar, UX engineer. Designed in Figma, built with Claude Code.

## View it

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 4321
```

Then visit http://localhost:4321. `phone.html` shows the site inside a phone frame for checking the mobile layout.

## Files

- `index.html` — the site (a full HTML page).
- `portfolio.src.html` — the source fragment that `index.html` is built from.
- `akash-portfolio-sample.html` — the same fragment, used for the published preview.
- `img/` — images used by the site.
